This project is my first fully self‑contained RISC‑V processor: a single‑stage, 32‑bit core that speaks the RV32I instruction set and runs entirely inside the Makerchip TL‑Verilog playground. Starting from an empty template, I pieced together a straightforward fetch–decode–execute datapath, wired up a tiny register file and memory interface, and then used a short assembly program—the classic “add the first nine natural numbers” loop—to prove that the machine really works. Because the whole design lives in TL‑Verilog, I could describe control flow and datapath timing at a high level, yet still dive down to individual signals in Makerchip’s live waveform viewer to chase bugs and measure latency. Although the core is intentionally minimalist (no pipeline hazards or fancy forwarding yet), it gave me hands‑on practice with the full digital flow—from RTL all the way to cycle‑accurate simulation—and set the stage for future extensions such as pipelining, a memory‑mapped I/O bus, or even synthesis with an open‑source PDK. If you’re curious, the complete source lives in the repository and can be copied directly into Makerchip for an instant, browser‑based spin‑up of the CPU.
